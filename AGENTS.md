# README files

Whenever there is a README.md file in a directory, be sure to read it and follow any instructions or guidelines it contains.

# ExecPlans

When writing complex features or significant refactors, create and use an `ExecPlan` (as described in [.agent/PLANS.md](.agent/PLANS.md)) from design to implementation. You can find existing ExecPlans in the [.agent/](.agent/) folder.

Once an ExecPlan is finished, move it to the [.agent/archive/](.agent/archive/) directory.
